# 🛍️ Vrinda Store Annual Sales Analysis | Excel Dashboard



## 📌 Project Overview

The **Vrinda Store Annual Sales Analysis** is an interactive Excel dashboard project designed to analyse retail sales performance, customer purchasing behaviour, order fulfilment, and sales channel contribution.

This project converts raw sales data into meaningful visual insights that help understand business performance and support data-driven decision-making.

## 🎯 Business Objectives

- Analyse monthly sales and order trends.
- Compare sales contribution by gender.
- Monitor order fulfilment performance.
- Identify the top-performing states.
- Analyse customer age groups and gender.
- Compare sales across different channels.
- Build an interactive dashboard using Excel slicers.

## 🛠️ Tools & Technologies

- **Microsoft Excel**
- PivotTables and PivotCharts
- Interactive Slicers
- Data Analysis
- Data Visualisation
- Business Intelligence

## 📊 Dashboard Features

| Dashboard Component     | Purpose                                                    |
| ----------------------- | ---------------------------------------------------------- |
| 📈 Orders vs Sales      | Analyse monthly sales and order trends                     |
| 👥 Men vs Women         | Compare sales contribution by gender                       |
| 📦 Order Status         | Analyse delivered, returned, refunded and cancelled orders |
| 🛒 Sales Channels       | Compare Amazon, Myntra, Flipkart and other channels        |
| 🌍 Top 5 States         | Identify leading states by sales                           |
| 🧑‍🤝‍🧑 Age vs Gender  | Understand customer segment distribution                   |
| 🎛️ Interactive Slicers | Filter results by month, channel and category              |
